# JET Restaurant Growth Agent

A SAAF Project hackathon agent for Just Eat Takeaway (JET). It acts as a
"growth manager" for small restaurant partners: it analyses a restaurant's
listing, menu, reviews, sales and nearby competitors, proposes concrete changes
with an estimated impact, and applies them to the listing only after the owner
approves.

> **Status: work in progress.** The synthetic data layer and the core models are
> written. The agents, the graph and the demo UI are still stubs. See
> [Status](#status) for the exact split.

## What the agent does

Why JET cares: JET earns commission on order value (about 15% on marketplace
orders, about 30% when JET delivers) plus advertising revenue. Every
recommendation must tie back to more orders, higher basket value, better
conversion, or justified ad spend.

```
load_context -> [reviews, menu, pricing, promo_ads] (in parallel)
             -> impact -> rank -> human_approval -> apply -> summary
```

- **Specialist agents** read the data and emit recommendations. They never
  change anything themselves.
- **Evidence is mandatory.** Each recommendation references real rows (review
  ids, order stats). No evidence means no recommendation.
- **Impact numbers are not generated by the LLM.** They come from simple,
  explainable heuristics, and the formula is shown to the user.
- **Nothing is written without approval.** Approved changes are applied as JSON
  patches to the listing and logged, so they can be reverted.

## How to run it

Requirements: Python 3.11 or newer.

```bash
# 1. Install
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Configure
cp .env.example .env               # then fill in ANTHROPIC_API_KEY

# 3. Generate the synthetic database (writes data/jet.duckdb)
python -m growth.data.seed
```

Not available yet (the files exist but are empty stubs):

```bash
python -m growth.cli <restaurant_id>   # run the graph headless
streamlit run app/main.py              # demo UI
pytest -q                              # needs tests/conftest.py first
```

### Environment variables

| Variable | Required | Default | Purpose |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | yes | none | Claude API key |
| `MODEL_MAIN` | no | `claude-sonnet-5-5` | Model for the specialist agents |
| `MODEL_FAST` | no | `claude-haiku-4-5-20251001` | Cheap model for per-item work such as review tagging |
| `JET_DB_PATH` | no | `data/jet.duckdb` | Location of the DuckDB file |

## What each file does

| Path | Purpose | State |
|---|---|---|
| `growth/data/seed.py` | Deterministic synthetic data generator: 8 restaurants, 8 weeks of orders, reviews, competitors, ads, listings | written |
| `growth/data/queries.py` | Database schema and all SQL. Agents never write SQL inline | written |
| `growth/state.py` | Pydantic models: `Recommendation`, `Impact`, `GraphState` and helpers | written |
| `growth/llm.py` | `call_structured()`: calls Claude with a Pydantic schema via tool use, retries once on a validation error, then skips and logs | written |
| `growth/graph.py` | LangGraph wiring of the flow above | stub |
| `growth/agents/reviews.py` | Review themes and complaints per dish | stub |
| `growth/agents/menu.py` | Descriptions, photos, dish pruning, bundles | stub |
| `growth/agents/pricing.py` | Price positioning against nearby competitors | stub |
| `growth/agents/promo_ads.py` | Promo timing for slow slots and sponsored listing budget | stub |
| `growth/agents/impact.py` | Heuristic impact estimate per recommendation | stub |
| `growth/tools/listing.py` | Read and apply JSON patches to the mock listing | stub |
| `growth/cli.py` | Headless runner | stub |
| `app/main.py` | Streamlit demo UI | stub |
| `tests/test_seed.py` | Checks that every planted problem is findable through the queries | written, needs a `conftest.py` |
| `CLAUDE.md` | Full project spec and conventions for AI coding assistants | written |

## Example input and output

**Input:** a restaurant id from the synthetic data, for example `r_bella_napoli`.
All data is synthetic. The seed plants known problems so the agents have
something real to find:

| Restaurant | Planted problems |
|---|---|
| `r_bella_napoli` (Pizza) | Soggy Calzone reviews, missing photos on bestsellers |
| `r_spice_route` (Indian) | Tuesday afternoon dead slot, overpriced Mains |
| `r_golden_wok` (Chinese) | Missing photos and descriptions, cold Chow Mein |
| `r_burger_barn` (Burgers) | Soggy Fries, overpriced Sides |
| `r_sushi_zen` (Sushi) | Tuesday afternoon dead slot, wasted ad spend |
| `r_taverna` (Greek) | Missing photos, a dish that never sells |
| `r_pho_house` (Vietnamese) | Overpriced Starters, missing descriptions |
| `r_petit_bistro` (French) | None (control restaurant) |

**Output:** a ranked list of recommendations. The shape below is illustrative,
not real output, because the agents are not built yet:

```json
{
  "id": "menu-1",
  "agent": "menu",
  "title": "Add photos to your 3 bestsellers",
  "rationale": "Your top-selling mains have no photo, which lowers conversion.",
  "evidence": [
    {"kind": "menu_item", "ref": "r_bella_napoli_m03", "detail": "bestseller, photo_url is null"}
  ],
  "patch": [
    {"op": "replace", "path": "/menu/3/photo_url", "value": "https://..."}
  ],
  "impact": {
    "orders_per_week": 0.0,
    "gmv_eur_per_week": 0.0,
    "jet_revenue_eur_per_week": 0.0,
    "ad_spend_eur": 0.0,
    "formula": "filled in by growth/agents/impact.py"
  },
  "confidence": "med"
}
```

## Safety and data

- All data is synthetic. Do not commit real restaurant, customer or order data.
- Keep API keys in `.env`, which is gitignored. Never commit credentials.
- The agents cannot change prices or launch ads without owner approval.
- The only network calls are to the Anthropic API.

## Stack

Python, LangGraph, Anthropic SDK, Pydantic v2, DuckDB, Streamlit.
